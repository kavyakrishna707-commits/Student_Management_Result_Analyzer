# Student Management System & Result Analyzer

A Python-based console application developed as part of a certification course. It manages student records and analyzes academic performance using Python built-in functions and standard libraries.

## Features

* Add, view, search, update, and delete students
* Manage subject marks
* Calculate total, average, and percentage
* Generate grades and Pass/Fail results
* Identify failed subjects
* Student ranking
* Top student analysis
* Class statistics
* Subject-wise analysis
* Overall result report
